🎩 Hudini Host

Сервер оверлея на этом компьютере. Не закрывай чёрное окно программы, пока идёт стрим.

📁 Место для файлов модераторов

Модераторы загружают картинки, GIF и видео. Они хранятся на этом компьютере в папке программы, зашифрованными. Сколько места им дать?

1 Ссылка от модератора

Попроси модератора нажать в пульте «📋 Копировать» и вставь эту ссылку сюда. Нужно сделать один раз, программа её запомнит.

2 Ссылка для OBS

  1. OBS → Источники → + → Браузер (или открой уже созданный)
  2. В поле URL вставь эту ссылку, ширина и высота = разрешению холста (обычно 1920×1080)
  3. Выдели источник и нажми Ctrl+F, чтобы растянуть его на весь экран

3 CS2 на оверлее (по желанию)

Чтобы на оверлее были твои K/D/A, HP, деньги, счёт и т.д. Нажми кнопку и перезапусти CS2.

🎛 Панель в OBS (по желанию)

Маленькая панель прямо в OBS: статус, кнопка «Спрятать оверлей», стоп звуков и пауза модераторов.
  1. В OBS: меню Доки → Пользовательские доки браузера…
  2. Имя: Hudini, адрес: http://localhost:7777/dock → Применить
  3. Перетащи появившуюся панель, куда удобно

⚙ Для продвинутых
Свой адрес для модераторов. Вместо бесплатного туннеля Cloudflare: Tailscale Funnel, свой туннель Cloudflare или свой домен. Направь его на http://127.0.0.1:7778 и впиши адрес вида wss://мой-адрес/mqtt. Пусто = обычный туннель.
Адрес и пароль для пульта. Обычно пульт находит программу сам. Если нет, модератор вписывает их в пульте: «Комната» → «Для продвинутых». Никому больше не показывай.
Новый пароль модераторов. Все модераторы отключатся на пару секунд и подключатся снова сами. Чтобы закрыть доступ человеку насовсем, модератор нажимает в пульте «♻ Сменить ключи», а ты вставляешь новую ссылку в шаг 1.
