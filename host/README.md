# Overlay Host — программа для стримера

Свой сервер оверлея на ПК стримера и живые данные из CS2.

**Зачем:** OBS получает команды напрямую с этого же компьютера (без задержек и без зависимости от общего сервера). Модераторы подключаются через бесплатный туннель Cloudflare с паролем, а адрес пульт находит сам. Если туннель не поднялся, всё работает по-старому через общий сервер.

## Как пользоваться

1. Скачай программу на странице [Releases](https://github.com/niko-ua-designer/overlay/releases/latest): для Windows это `OverlayHost-windows.exe.zip`.
2. Распакуй её **в отдельную папку**, туда же она сохранит настройки, и запусти.
   Windows может показать «Система Windows защитила ваш компьютер»: нажми «Подробнее» → «Выполнить в любом случае» (у программы нет платной подписи).
3. Откроется страница управления `http://localhost:7777`:
   - **Шаг 1:** вставь ссылку, которую прислал модератор (в пульте кнопка «📋 Копировать»). Это делается один раз.
   - **Шаг 2:** скопируй «Ссылку для OBS» и вставь её в URL источника «Браузер» в OBS (1920×1080, затем Ctrl+F).
   - **Шаг 3 (CS2):** нажми «🎯 Подключить CS2» и перезапусти игру.
4. Чёрное окно программы держи открытым, пока идёт стрим. Закроешь его — оверлей пропадёт со стрима.

Модератор при этом ничего не меняет: просто открывает свой пульт на GitHub Pages. Вверху появится «онлайн · сервер стримера».

## CS2

Программа кладёт в папку CS2 файл `gamestate_integration_streamoverlay.cfg`: это официальная функция Valve (Game State Integration), игра сама присылает данные. Античит её не трогает: так работают все HUD-оверлеи и подсветка клавиатур.

В пульте кнопка «🎯 CS2» добавляет элементы: карточку игрока, K/D/A, HP и броню, счёт карты, деньги, оружие и всплывашку DOUBLE / TRIPLE / QUAD KILL / ACE.

## Безопасность

- Страница управления и порт для OBS доступны только с этого компьютера.
- Модераторы через туннель входят по случайному паролю, который пульт получает в зашифрованном виде.
- Подделать команды на экран нельзя, они подписаны ключом модератора.
- Данные из CS2 принимаются только с секретным токеном.

## Для разработчиков

```sh
cd host && npm install
bun run server.js          # запуск из исходников
sh build.sh                # сборка .exe / linux / mac в host/dist
```

Переменные: `OVERLAY_PORT` (7777), `OVERLAY_NO_TUNNEL=1`, `OVERLAY_TUNNEL_URL=wss://свой.домен/mqtt` (свой адрес вместо Cloudflare), `OVERLAY_HOST_DIR` (папка настроек).
