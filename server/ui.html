1 Ссылка для OBS

  1. OBS → Источники → + → Браузер (или открой уже созданный)
  2. В поле URL вставь эту ссылку, ширина и высота = разрешению холста (обычно 1920×1080)
  3. Выдели источник и нажми Ctrl+F, чтобы растянуть его на весь экран

📁 Место для файлов модераторов

Модераторы загружают картинки, GIF и видео. Они хранятся на этом компьютере в папке программы, зашифрованными. Сколько места им дать?
Cloudflare больше нет. Модераторы подключаются напрямую. Скопируй новый код и отправь его модератору: старые ссылки перестали работать.

Комната обновлена

Она осталась от старой версии Hudini, и модераторы не могли по ней войти. Hudini Host сделал новую комнату. Осталось два шага:

  1. Вставь в OBS новую ссылку (источник «Браузер»)
  2. Отправь модераторам новый код

🎛 Пульт на этом компьютере

Полный пульт в отдельном окне, без кода и пароля. Модераторы могут работать одновременно с тобой.

🔒 Что можно модераторам

Выключенное пропадает из пульта модераторов и не попадает на стрим, даже если его уже добавили.

🌐 Адреса, по которым тебя можно найти

СетьАдресЧто нужно
Через Porthole делись только портом 7778. Порт 7777 — это управление твоим Hudini, его не показывай никому.

2 🎛 Панель в OBS (по желанию)

Маленькая панель прямо в OBS: статус, быстрые выключатели, элементы на экране с глазиками, кто на связи и CS2 с подсказкой «файт».
  1. В OBS: меню Доки → Пользовательские доки браузера…
  2. Имя: Hudini, адрес: http://localhost:7777/dock → Применить
  3. Перетащи появившуюся панель, куда удобно

3 CS2 на оверлее (по желанию)

Чтобы на оверлее были твои K/D/A, HP, деньги, счёт и т.д. Нажми кнопку и перезапусти CS2.
