Комната (стример)

У каждого стримера своя комната, ключи и ссылка. Команды на экран подписываются ключом из этого пульта: без него управлять нельзя. «Бэкап» сохраняет всё в файл под паролем.

🎞 Сцены

Клик по сцене заменяет весь экран, Shift+клик добавляет поверх. Например: «Начало», «Перерыв», «Итоги».

Текст

Картинки, видео, сайты

Файлы можно перетащить на холст или вставить картинку из буфера (Ctrl+V).

📚 Библиотека

Сохраняй готовые элементы (с анимацией) кнопкой «📚» в инспекторе, а потом добавляй в один клик в любую комнату.

Вебка

Откроется вкладка VDO.Ninja: выбери камеру и нажми старт. Не закрывай эту вкладку, пока вебка нужна на стриме.

Таймеры и счётчики

Чат Twitch выкл

Нужен для «счётчика чата». Только читает чат, без входа в аккаунт. Считает, пока этот пульт открыт.

Чтобы видеть, куда ставить элементы. Стрим на Twitch отстаёт на несколько секунд.
