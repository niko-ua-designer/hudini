# Проверка Hudini 1.0.0-rc.4 на живом стриме

Около 15 минут. Нужны: стример на Windows с OBS и модератор с пультом. Отмечай ✅ или ❌ и пиши, что увидел. Если пункт ❌, сделай скриншот и запиши время: по нему легко найти строку в журнале программы.

## Стример: установка (5 мин)

- [ ] Скачать `HudiniHost-windows-1.0rc4.zip` со страницы релиза `v1.0.0-rc.4`, распаковать **в новую папку**, запустить. Старую программу (Overlay Host 1.x или Hudini Host rc.3) закрыть. В папке: `Hudini Host.exe`, `hudini-server.exe`, `data/`, `README.txt`.
- [ ] Страница программы открылась сама, сверху карточка «📁 Место для файлов модераторов». Нажать «Сохранить и продолжить» (или поменять лимиты).
- [ ] Вставить в шаг 1 ссылку от модератора (пульт → «📋 Копировать»), нажать «Сохранить».
- [ ] В OBS у источника «Браузер» заменить URL на ссылку из шага 2. Размер **1920×1080**.
- [ ] В «Состоянии» программы: OBS «виджет подключён», туннель «работает», поиск адреса «работает».

## Модератор: подключение (3 мин)

- [ ] Открыть пульт (можно установить как приложение). Плашка вверху зелёная: «онлайн · Hudini Host».
- [ ] Плашка OBS: «OBS: 1920×1080» без ⚠.
- [ ] При подключении всплыло «Место для файлов: свободно …», под кнопкой «Файл» видно «Место: … · файлов: …».
- [ ] Нажать ❓ → «Показать обучение ещё раз», пройти до конца, выбрать анимации и раскладку.

## Во время стрима (5 мин)

- [ ] Текст: добавить, подвигать, спрятать 👁 и показать. На стриме меняется сразу.
- [ ] Картинка с компьютера и GIF: появились на стриме, GIF анимируется.
- [ ] Ctrl+C → Ctrl+V копирует элемент.
- [ ] Видео с компьютера со звуком, громкость меняется.
- [ ] Таймер и голосование: надписи на стриме на нужном языке (Комната → «Надписи на стриме»).
- [ ] Чат Twitch: сообщение по клику появилось на стриме.
- [ ] CS2: карточка игрока показывает данные, после мульти-килла всплывает DOUBLE/TRIPLE.
- [ ] Второй модератор (по приглашению) видит то же и может менять.

## Проверка восстановления (2 мин)

- [ ] Стример закрывает программу: в пульте «Hudini Host выключен» или «⏳ Ждём Hudini Host», а не ошибка.
- [ ] Стример запускает программу снова: пульт подключился сам в течение минуты, экран на стриме вернулся.
- [ ] Кнопка 🧹 «Удалить неиспользуемые файлы» удаляет только то, чего нет на экране, в сценах и библиотеке.

## Трей и автозапуск (3 мин)

- [ ] Закрыть окно программы крестиком: значок Hudini остался в трее у часов, стрим и пульт работают дальше.
- [ ] Клик по значку в трее (или пункт «Открыть») возвращает окно; пункт «Выход» закрывает программу целиком, в диспетчере задач не остаётся `hudini-server.exe`.
- [ ] Включить автозапуск, перезагрузить ПК: программа стартует сама (в трее), пульт подключается в течение минуты.
- [ ] Выключить автозапуск, перезагрузить ПК: программа сама не стартует.
- [ ] Если у тестера осталась папка с rc.3: запустить её, rc.3 сама находит обновление до rc.4 и ставит его.

## Если что-то не так

- Журнал программы: внизу её страницы. Скопируй последние строки.
- В пульте: F12 → Console, скриншот красных строк.
- Сообщить: https://github.com/niko-ua-designer/hudini/issues
